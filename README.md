# Installation

```bash
$ git clone [https://github.com/FiifiQwontwo/Ena_Spotter_a.git]

```


create a virtual environment to install dependencies

```bash
python -m venv venv
./venv/Scripts/activate
cd Veh
```
Then install the dependencies:
```bash
(venv) $ pip install -r requirements.txt
```
Once pip has finished downloading the dependencies: 
```bash
(venv)$ cd project
(venv)$ python manage.py makemigrations
(venv)$ python manage.py help(this will show you commands look for the one under routes and run the 2)
(venv)$ python manage.py The_2_comands_under_route_run_1_by_1
(venv)$ python manage.py migrate
(venv)$ python manage.py runserver
```
and navigate to http://localhost:8000/api/route the collection its added to the code
